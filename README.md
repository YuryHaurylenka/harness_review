# Аудит Procura Harness

Репозиторий содержит материалы тестового задания по анализу harness для разработки с AI-агентами.

## Материалы

- [REVIEW.md](./REVIEW.md) — приоритизированные риски, рекомендации, статус контролей и разбор противоречий в исходном CODE.md.
- [CLAUDE.new.md](./CLAUDE.new.md) — предлагаемая замена рабочего брифа Claude Code.
- [PROMPTS.md](./PROMPTS.md) — фактический статус использования субагентов и отдельные проектные шаблоны для возможной мультиагентной проверки.

## Границы проверки

Это статический аудит предоставленного снимка harness. Команды, тесты и production-сценарии не запускались. В REVIEW отдельно различаются найденные исполняемые файлы, документированные, но не подтверждённые механизмы, и отсутствующие компоненты.

В рамках этой работы отдельные субагенты не запускались. Шаблоны в PROMPTS.md не являются журналом выполненных запусков.

## Статус

Итоговые документы предназначены для оценки и обсуждения архитектуры harness; они не являются исправлением или развёртыванием исходного harness.
